QRIS Dynamic Generator - XAMPP

1. Extract folder ini ke C:\xampp\htdocs\qris-dynamic-dashboard-xampp
2. Start Apache dari XAMPP Control Panel.
3. Buka http://localhost/qris-dynamic-dashboard-xampp/
   Jika Apache memakai port 8080: http://localhost:8080/qris-dynamic-dashboard-xampp/
4. Setelah mengganti versi project, tekan Ctrl+F5 di browser.

Catatan:
- Scan foto QR berjalan di browser. jsQR dimuat dari CDN, jadi koneksi internet diperlukan untuk fallback scanner.
- Template poster berada di assets/qris-template.png.
- Hasil Generate mengganti area QR pada template, lalu bisa di-download sebagai PNG atau dicetak.
- Gunakan hanya QRIS merchant yang sah dan memang Anda kelola.
